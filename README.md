# 📚 Book Genre Classifier

This Python project takes a list of book titles and automatically classifies them by genre using the Google Books API.

## 🚀 Features

- Fetches genre information for each book via the Google Books API
- Groups books by genre and displays them neatly
- Simple and beginner-friendly code structure

## 🛠 Requirements

- Python 3.6+
- `requests` library (install via `pip install requests`)
